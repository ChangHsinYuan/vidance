### 附记 5（2026-10-10 傍晚）：agent run --with WebUI 外壳引号解析 bug
- **现象**：WebUI `/agent run post.edit --with '{"..."}'`（CLI 风格外壳引号）→ "--with 非法 JSON: Extra data: char 173"
- **根因**：api_server.py run 分支 `rj.find('{')` 只剥前引号（`'{"..."}'` → `{"..."}'`），尾引号留给 json.loads 报 Extra data；CLI 里 bash 预先剥引号所以没暴露
- **修复**：JSON 边界提取改为 `find('{')` + `rfind('}')` 首尾都取（外壳引号/前后缀杂物全兼容）
- **验证**：单测两种引号风格 + 宿主 8894 + 容器 9401 用用户原命令（带外壳引号）实测 ok=true（各 ~69s）
- **结论**：WebUI 里带不带 `'...'` 外壳引号都能跑
