## P1 封面【核心】

- **标题**：Vidance——基于本地多模型编排的 AI 短片生成系统
- **副标题**：从一句话、一篇小说，到有声短片 | 中期答辩
- 视觉：成片 3-4 张缩略图拼贴（auto/fast/edit/svg/ppt 各一）
- 讲稿：我们在做的是一个"AI 当剧组"的系统——一句话创意进去，成片出来。

## P2 背景与定位【核心】

- 痛点：视频内容生产门槛高——编剧/拍摄/配音/剪辑多环节、多工具、多模型
- 定位：**"agent 当导演"**，不是单点 API，是全流程生产系统
- 原则：**应用层不做模型研发**，筛选组合现成开源模型，工程精力花在编排/一致性/质量
- 视觉：剧组角色映射表（制片人=agent / 编剧=LLM / 摄影=Wan/H3 / 配音=CosyVoice / 审片=多模态 LLM / 剪辑=ffmpeg）
- 讲稿：我们把一个视频剧组的每个工种都映射成一个组件，agent 是导演。

## P3 总体架构【核心】

- 三层：产品层（五条产出线）→ 编排层（CLI/WebUI/API/t2c/多智能体/SKILL）→ 引擎层（11+ 本地模型分卡）
- 混合模式：确定性流程硬编码，创意与判断交 LLM
- 核心创新：**角色锚**——参考图经 3D 重建/FLUX 链路按镜头角度渲染起始帧，跨镜头不漂移
- 视觉：三层架构图（roadmap §2 直接可用）+ 角色锚小流程图
- 讲稿：底下是 4×4090 上分卡部署的十一个本地模型，中间是编排，上面是多形态产出。

## P4 能力全景（版本矩阵）【核心】

- v0→v17 时间轴/矩阵：15+ 条线完成（MVP→角色一致性→长视频后期→3D→营销号→特效→WebUI→拼接→多智能体→轻量化四线→PPT→视频编辑→开源整合）
- 标注三个"代表作"格子：v11 多智能体（28 agents）、v16 编辑全家桶、v17 小说→短剧
- 视觉：横向版本时间轴，完成绿/移交黄/待开发灰
- 讲稿：六周推进了二十多条版本线，十五个以上已经完成。

## P5 模型底座与部署【可裁剪】

- 模型清单表（T2V×3 / T2I / 3D×2 / 编辑×5 / TTS 双引擎 / whisper / RIFE / bge）
- 4×4090 分卡调度表（端口+显存）+ docker 五档 tier（none→full）
- 一键 start_services + preflight 预检（硬依赖拦/软依赖降）
- 讲稿：所有模型都是现成的，我们的工作是让它们在一台四卡机器上各司其职。

## P6 亮点一：小说→短剧全链路【核心】

- 输入 3 章小说 → 输出多镜头有声短剧，六步钉死 AI 不一致性：
  ① RAG 分章索引 + **人物卡=外貌唯一来源**
  ② 风格/色彩/光影/氛围四键**全局锚点**
  ③ **四视图设定图**锁定角色
  ④ 分镜铁律 + **代码层兜底**（LLM 不听话就拦截修复）
  ⑤ SKILL 风格包确定性覆盖
  ⑥ 音色绑定 + 断点自愈
- 视觉：全链路流程图 + 人物卡 JSON 截图 + 四视图设定图实图（output/auto_20261015_211033/character_ref.png）
- 讲稿：AI 生成的最大问题是不一致，我们的答案是把每个环节的不一致都"钉死"。

## P8 亮点二：全链质检闭环【核心】

- 审片 5 维打分（≥7 过审，重试≤2 取最高）——shot3 首审 5 分→重试 8 分真实案例
- S4 scrub：分镜违例检测→定向修复→仍违例不采纳
- TTS 护栏：whisper 反转写+拼音校验+词界裁剪，**绝不落盘幻觉音频**
- 字幕纠正：文本以剧本为准，Levenshtein 对齐修错字
- 视觉：质检漏斗图（生成→审→拦→修→过）
- 讲稿：AI 的输出一律不可信，所以每个环节都有质检员。

## P9 亮点三：工程化韧性【可裁剪】

- 断点续跑（原子 checkpoint，坏镜重做好镜复用）
- 素材 md5 全局缓存（第二次 0.0s vs 首次 10.4s）+ 搜索 TTL
- 降级哲学：GPU 全挂仍能降级出片不崩
- docker 五档部署 + preflight
- 讲稿：系统在烂环境下也要能出活——这是生产系统的底线。

## P10 亮点四：多形态输出与多入口【可裁剪】

- 五条产出线：视频 / 营销号 / SVG 动画 / PPT / Blender 3D（同一编排底座）
- 四种入口：CLI / WebUI 对话 / HTTP API（29 工具）/ 中文自然语言（t2c 微调模型）
- 多智能体：28 agents 四层分层 + chain 链式 + 轨迹可视化
- 视觉：五线四入口矩阵 + WebUI 截图（:8894/ui）
- 讲稿：同一个底座，长出五种内容形态；同一个能力，四种打开方式。

## P11 典型问题案例：配音硬伤五轮排查【可裁剪】

- 现象→根因链：0.6s 废音频（fp16 并行采样崩坏）+ 幽灵音节（克隆 prompt 被当上文续写）
- 修复：客户端串行锁+护栏，定版"话题中性短句"克隆样本
- 方法论：**追到根因、验证干净才算完**；服务端保持官方原样，全改客户端
- 视觉：排查时间线（日志实锤截图）
- 讲稿：这个案例最能体现我们的排障深度——五轮迭代，每轮都有实证。
